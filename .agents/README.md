# 分割指示の使い方

各`rules/*.md`は、担当作業のときにエージェントが明示的に読む詳細仕様であり、すべてが自動読込されるファイルではない。
エントリーポイントはリポジトリ直下の[AGENTS.md](../AGENTS.md)。その参照表で必要なファイルを選ぶ。

`AGENTS.md`という名前の階層別ファイルは対象フォルダーに置く。ルート起動時に子フォルダーの指示まで全て自動で含まれると仮定しない。
同じ階層に`AGENTS.override.md`がある場合は通常の`AGENTS.md`より優先されるため、既存ファイルを確認する。無断で削除しない。
ユーザー全体のCodex設定も別に存在し得る。このパッケージは`~/.codex`を変更しない。

詳細ルールの「業務仕様」は原文・承認済み発言由来。「実装上の具体化」は今回作成する工程・安全策であり、新しい業務要求ではない。
「仮仕様」は実画像・操作確認で調整する。「要確認」は承認を得るまで本番仕様を確定しない。

公式の読込仕様と容量条件は[参照資料 E01](../docs/source-index.md)を参照。リンクを記載するだけで参照文書の全文が自動挿入される仕組みではない。
