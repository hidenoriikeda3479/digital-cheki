# 決定・仮仕様・未決事項の区分

このファイルは、原文を編集せず会話で確定した変更を重ねる台帳。ユーザーの決定と、実装済みかどうかは別。
根拠は[発言一覧](decision-evidence.md)、原文は[要求定義](requirements.md)、制約は[未決事項](open-questions.md)。

## 明示的な決定
今回の追加：設定メニューへログアウトを含める（ユーザーの最新指示）。以前の「設定内のログアウトは不要」をこの範囲で変更する。グループ・ファンは既存のログアウト処理へ接続し、ゲストの既存ログアウトも維持する。

今回の追加：DEC-073。ホームの両アイドル欄はカードをタップすると詳細モーダルを開く。写真・名前・グループ名とX／Instagramボタンを表示する。ユーザー確認により、テスト用のリンク先は各サービスのトップページ。DEC-071の「表示だけ」をこの範囲で変更する。人物画像は引き続き同梱モック素材。根拠C73。

今回の追加：DEC-072（根拠C72）。ホームのピックアップ人数を非表示にし、同じカード形式で人気急上昇中のアイドルを追加。直近7日間の撮影日時で、送信完了した写真を集計する。複数参加は各アイドルへ1枚ずつ加算。上位最大3名、同数は名前順。原文全体のランキング仕様が完成したという意味ではない。

今回の追加：DEC-071（根拠C71）。ファン側ホームに、全グループの画像登録済みアイドルからランダムに最大10名のピックアップを表示する。今回は表示のみでカード遷移を追加しない。現在のモック素材は3名分。検索・ランキングを完成扱いにしない。

| DEC-070 | 写真受取はファン側ホームのCタイプのスタックモーダルで完結し、独立した受信画面・受信タブを廃止。共通タブはホーム／アルバム／設定 | C70。D1のヘッダー・受付・最近のアルバムを維持。受付ごとの対象確認・期限・失敗・手動再試行をホームとモーダルへ移し、写真ID・保存・認可・再受信禁止を維持する。原文の論理画面IDは残す |

DEC-001〜016は旧decisions.mdの番号を維持し、内容の出典を追加。上表だけで原文の業務要件全体を代替しない。
