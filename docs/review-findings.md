# 前版と今回の照合結果

## 結論
前版にも1アプリ・通信だけモック・7日保管・手動再送・iPhone先行等の主要条件は記載されていた。
ただし、**要件全件の対応、担当別の読込、未決/仮仕様/設計上の追加の分類まで検証できる状態ではなかった**ため、今回分割と追跡表を追加した。
全チャット全文は取得できておらず、「すべての別チャットの決定を完全網羅」とはしない。

## 改善点
| 観点 | 前版の状態 | 今回の対応 |
|---|---|---|

| 他チャット | 一般的な会話参照 | 2回検索の取得範囲・重複・全文未取得・無関係資料除外を記録 |

| 試験 | 確認観点中心 | 原文60受入条件＋横断28ケース。未実施を明記 |

## 原文を保持した不一致
- 目的の3番目が「画面を確認」。旧原文・会話には撮影実績蓄積の目的があるが、原本は変更していない。
- 未決一覧6件と合計14の差。存在しない項目を補っていない。
- アンケートA-007/A-008、G-002再設定参照の差をOPENとして保持。
- 画面遷移図の再送戻り等の省略は、機能要件・画面表と照合する。
- 不採用削除と未完了保護の段階、全件通知と各写真期限の組合せは詳細化が必要。

## 今回追加した設計上の具体化
結果不明の内部状態、仮時計、DB/ファイルの復旧、アカウント切替の世代、公開bundleのモック除外等は、既存要求を守るための実装規約である。
それらを「ユーザーが名称・数値まで了承した新業務要件」とはしていない。

## 原文と検証範囲
requirements.mdと旧原文R2をバイト単位で保存。ハッシュはsource-indexに記録。旧AGENTS/decisionsはZIPのreviewへ退避。
