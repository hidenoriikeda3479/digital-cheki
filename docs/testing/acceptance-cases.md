## DEC-070のホーム受取確認（2026-10-14）

AT-P1-DWN-001〜005 / P1-REC-001/002のUI確認はホーム上のC型モーダルへ読み替える。対象確認はホームの矢印から全受付・4枚目以降も表示する。0/1/3/10枚、分母固定、連打、転送100%と保存確定の区別、部分／全失敗、期限切れ、手動再試行、応答喪失照合、長い待機からの操作復帰と背景停止をreceive-modal.test.tsxで自動試験。ホーム維持とアルバム更新はauth-screen.test.tsx、保存・再起動・利用者分離は既存の実ファイル/SQLite結合試験を実行した。原文の要件や実機未確認区分は維持する。[iPhone手順](../architecture/home-receive-modal.md)は実機確認待ち。
